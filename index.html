RefactorIQ is now available on Google Cloud Marketplace

RefactorIQ, Estuate’s AI migration agent for moving Alteryx and Dataprep workflows to Incorta, is now available on Google Cloud Marketplace, giving Google Cloud customers a direct way to buy and start using it.

RefactorIQ now available on Google Cloud Marketplace

RefactorIQ+Google Cloud

On 29th October, we are pleased to announce that RefactorIQ, Estuate’s agentic AI platform for enterprise migration and modernization, is now available on Google Cloud Marketplace. Google Cloud customers can now access RefactorIQ directly through the Marketplace, with streamlined procurement, automated onboarding, and billing consolidated into their existing Google Cloud account.

What is RefactorIQ?

RefactorIQ is Estuate’s family of agentic AI solutions built for complex enterprise upgrade, migration, and modernization programs. The platform analyzes existing workflows, identifies dependencies, assesses risk, and automates refactoring, reducing the manual effort and hidden risk that typically slow down large-scale transformations.

Alteryx and Dataprep to Incorta migration, now on Google Cloud Marketplace

The Marketplace listing covers RefactorIQ’s AI migration agent for data analytics modernization, helping organizations move from tools like Alteryx Designer and Google Dataprep into a governed Incorta data model. RefactorIQ agents analyze existing ETL pipelines, generate structured implementation proposals, and produce SQL pipelines, documentation, and audit trails, giving data engineering and analytics teams a faster, more reliable path to modernization.

“

Data teams shouldn’t have to spend months manually rebuilding workflows to modernize. With RefactorIQ on Google Cloud Marketplace, our customers can buy through their existing Google Cloud account and start migrating faster, with the documentation and audit trails their teams need.

What this means for Google Cloud customers

For enterprise IT leaders, data teams, and technology decision-makers already on Google Cloud, the RefactorIQ listing removes the friction that typically slows adoption of a new platform. Customers can now:

  • Subscribe directly through Google Cloud Marketplace without a separate vendor procurement process
  • Apply existing Google Cloud committed spend toward RefactorIQ, maximizing the value of cloud investments already in place
  • Consolidate billing into a single Google Cloud invoice alongside other services
  • Get up and running faster, with onboarding, billing, and runtime fully integrated with the Google Cloud environment

Get started with RefactorIQ

RefactorIQ is available now on Google Cloud Marketplace. Existing Google Cloud customers can subscribe directly from the console. Organizations interested in a personalized walkthrough can also request a demo to explore how RefactorIQ applies to their specific migration or modernization needs.
